- [verified] The Downloader tries providers one at a time. After each failure it asks the next provider only for local.missing(). When the list runs out it errors with 'Unable to download <hash>'. - [verified] A peer holding part of a blob serves most of what it has and then fails (it held 4 MiB and supplied about 3.4-3.98 MB). - [verified] Range requests work with GetRequest::blob_ranges(hash, ChunkRanges::bytes(a..b)), using the ChunkRangesExt trait. Ranges are in 1 KiB BLAKE3 chunks with a minimum granularity of 16 KiB chunk groups. Blobs::reader(hash) implements AsyncRead and AsyncSeek, but reading a range that is not downloaded returns an error, so it does not wait for the data. observe(hash) returns a Bitfield whose `ranges` field is public.
