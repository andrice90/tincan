- [high] Cwtch Managed/Hybrid Groups (provisional design): an always-online manager stores and relays messages. Members sign messages numbered by member id plus counter; a reconnecting member sends its last known id per member and the manager streams what was missed. The manager cannot forge messages, and censorship shows up as gaps. Conflicting membership changes resolve by the higher message id. (https://docs.cwtch.im/security/components/cwtch/hybrid-groups)
- [high] Jami swarm: one git repo per conversation, and the conversation id is the first commit's hash. The repo has /admins, /members, /devices and /banned, and bans need a majority of admin votes. Commits are validated oldest-first. Self-documented open problems: commit timestamps can't order bans, conflicting bans across partitions, and if nobody is online the conversation may never sync. The call host is set in swarm metadata or is the initial caller. (https://docs.jami.net/developer/jami-concepts/swarm.html)
